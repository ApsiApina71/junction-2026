# Demo day

Final submission closes **Sun 15.11 at 10:00** and does not accept late entries. Work backwards from that.
Tickets live in the Linear [Submission](https://linear.app/junction-2026-bossit/project/submission-bafb47e71313) project.

## Fri 13.11 by 23:59: pre-submission

- [ ] Team created on Junction Platform, every member joined with the team code.
- [ ] One member created the project as a DRAFT with the chosen challenge.

## Sat 14.11 evening: feature freeze (T−14h)

- [ ] Only demo-blocking fixes after this point.
- [ ] `main` is green, and the demo build is deployed and works in a fresh browser.
- [ ] Repo is public, so organizers can read the source.

## Sat night: video and deck

- [ ] Script: problem → demo → how it works → impact, mapped to Innovation, Impact, Implementation and the partner criteria in `docs/context/challenge.md`.
- [ ] Seed data and test accounts ready. No secrets on screen.
- [ ] Pitch video recorded, **at most 2:00** (strictly enforced), uploaded publicly to YouTube or Vimeo.
- [ ] Pitch deck exported as PDF.
- [ ] Backup screenshots in case of network or model failure.

## Sun 15.11 by 09:30: final submission

- [ ] Project name, punchline, description.
- [ ] Challenge(s).
- [ ] Technologies used.
- [ ] Video link (public, ≤2:00).
- [ ] Demo link and source code link (public repo).
- [ ] Source code publicity and credit preference.
- [ ] Pitch deck PDF.
- [ ] Phone number of every member.
- [ ] Discord username of every member.
- [ ] Status switched from **DRAFT to FINAL**. Drafts are not reviewed.
- [ ] README explains what we built and how to run it.

## Sun 15.11 10:30–13:00: peer review

- [ ] Whole team at the venue. Missing it loses main-prize eligibility.
- [ ] Each member reviews every project assigned to them.
- [ ] Someone stays at our table to demo.

## Sun 14:00 onwards: if we are top 5

- [ ] Pitch rehearsed and timed **before** Sunday. There is no rehearsal slot after review.
- [ ] 3 min pitch, the mic is cut at 3:00, then 3 min of judge questions.
- [ ] Demo runs from our own laptop. Staff check the connection beforehand.
- [ ] One presenter on stage with one handheld mic.
